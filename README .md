# SkillFi Frontend

## Overview

SkillFi is a hackathon project designed to help recruiters identify genuine candidate skills and reduce the problem of fake or unverified skill claims.

The platform allows users to upload certificates, showcase their skills, and take assessment tests to verify their proficiency. Verified skills help recruiters make more informed hiring decisions.

This repository contains the frontend implementation developed by me as part of a team hackathon project.

---

## Problem Statement

Recruiters often face difficulties in evaluating whether the skills mentioned on a candidate's resume are genuine.

SkillFi addresses this challenge by providing:

- Skill verification through assessments
- Certificate-based skill showcasing
- A centralized platform for skill validation
- Better transparency between candidates and recruiters
